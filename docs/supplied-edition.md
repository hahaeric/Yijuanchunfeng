# 用户提供版本的整理记录

本次将《论语》《大学》《中庸》的全文版本数据接入阅读模型，共 661 条：《论语》513 则、《大学》17 段、《中庸》131 段。其余六书不变，全库合计 5,041 条。

来源为用户提供的《国学经典大字注音全本 第2辑 论语·大学·中庸》，邓启铜注释，南京大学出版社，2014 年 5 月。原 PDF 共 218 页，无文字层；Word 是扫描识别结果，存在拼音穿插、重复文本框、注码和错字，不能直接复制覆盖。两个来源文件的文件名和 SHA-256 保存于正文数据的 `edition.sources` 中，原文件未改动，也未提交到仓库。

扫描 PDF 为版本依据，Word 和原语料辅助识别。使用逐页 OCR 提取正文候选，与原语料对齐后，对 407 个候选标点差异查看了扫描图，采纳 353 项、另校正 4 项，排除其余 OCR 错误。整理过程中修正了“关睢 / 关雎”“谏志不从 / 见志不从”“朝庭 / 朝廷”等已核实的实字差异。这里的全文接入不意味着逐字人工校定：识别不可靠的异文没有直接覆盖原字，仍有进一步逐字复核的空间。原版本《学而》的 17 则结构和已确认文字保留。

《大学》目录依次为明德、康诰、盘铭、邦畿、格物致知、听讼、诚意、正心修身、齐家、治国、絜矩。明德章末的“此谓知本，此谓知之至也”移入扫描本的格物致知章，连同朱熹补文作为独立阅读条目，明确标注来源，不将其混称为先秦原文。《中庸》的 33 章补入版本章名。原序言、页码、拼音、黑底通假字提示和页下注释不混入正文。

所有旧阅读条目 ID 保留；《大学》重排后仍以原 ID 找回阅读位置、收藏和笔记。旧版数字阅读序号按原 ID 迁移，新版直接保存当前条目 ID。本机拼音修改按新旧正文的汉字位置迁移；删除或改写的字不误套到其他字。新增补文使用新 ID。正文另存于 `mobile/src/data/supplied-edition-text.json`，离线发布数据由 `mobile/scripts/build-supplied-edition.mjs` 生成。拼音沿用程序结果并按汉字重新对齐，新增字用 pinyin-pro 生成，保留既有语境校正；不抄录纸本注音。繁体由程序转换，属于客户端阅读模式，不声称逐字复刻扫描本字形。

每条内容携带 PDF 页码以便后续复核。全书数据加载时拒绝重复 ID、跨书覆盖、遗漏旧条目和错位拼音。自动测试还核验目录顺序、补文搜索、旧阅读位置兼容、六书数据不变，以及生成数据可重复生成。测试能验证结构和程序行为，不能替代全文人工校勘。
