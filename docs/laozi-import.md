# 《老子》扫描本导入

新增“道家／老子”，按用户提供的邓启铜注释本《中华传统文化经典注音全本 第2辑 老子·大学·中庸》收录81章，每章一条阅读内容。仅新增《老子》，不替换已有《大学》《中庸》。

底稿为 `mobile/src/data/laozi-text.json`，记录各正文行的PDF页码、拼音初识材料、人工核对差异及来源SHA-256。扫描件正文位于PDF第15—117页。原PDF与OCR缓存保留在本机，均不提交。小黑底通假字说明、脚注序号、页下注释及图注不混入正文。保留本版的“万物作而弗始”“揣而梲之”等用字；客户端沿用简繁转换。

生成命令：`node mobile/scripts/build-laozi.mjs`；检查命令：`node mobile/scripts/build-laozi.mjs --check`。生成器仅在整行音节数与汉字数一致且字符合法时转入带声调的OCR读音；缺字、粘连、声调缺失等情况采用自动补注。人工从扫描页核实的读音单独记录位置校验。`pinyinOrigins` 逐字区分 `pdf` 和 `generated`，不把自动补注宣称为书中原注音。

书目和阅读条目追加到现有顺序末尾，云端阅读位图编号也只追加，避免影响已有进度、收藏及笔记。目录分组与书目数量根据实际数据展示；iPhone预编译数据同样包含新增正文和来源提示。

验证：`npm test` 覆盖81章完整性、版本特有文字、注音来源、逐字对齐、独立进度、搜索、原编号稳定性及iPhone预编译；另执行Android生产导出验证。
