# 账户、同步与统计

新增 SecureStore 原生模块，需要构建并安装新 APK，不能仅通过旧 APK 的内容更新启用。

客户端“我的”入口支持注册登录、周/月/年统计及管理员每日统计。后端为独立 Node.js 24 服务，SQLite 保存数据。

## 部署

运行 `node server/index.mjs`，默认端口8787。通过 HTTPS 反向代理提供服务，数据库 accounts.sqlite 必须使用持久化磁盘，并定期备份。单实例运行，不直接暴露 HTTP 到公网。

环境变量 PORT 配置监听端口；ADMIN_USER 和 ADMIN_PASSWORD 在首次启动时创建管理员，已有账号不会被覆盖，管理员名称禁止公开注册。用户名3—32位字母数字下划线，密码至少8位。密码通过部署平台秘密配置传入。ALLOWED_ORIGIN 设置 Web 客户端完整来源用于 CORS。

构建或发布客户端前设置 EXPO_PUBLIC_ACCOUNT_API_URL=https://你的账户服务域名。未配置地址时仍可本机阅读和统计，登录会显示未配置提示。

## 行为与限制

- 登录自动恢复云端进度、收藏、笔记、设置和拼音修正。游客数据独立保存，不自动归入账号。
- 数据变化1秒后同步，每30秒以及回到前台时重试或拉取；离线数据保存至账户专属本机缓存，重新登录后合并上传。
- 手机端令牌使用系统安全存储，重启后恢复登录和离线缓存；网页令牌仅在内存，刷新需重新登录。密码不在客户端保存。退出前需成功同步，否则保留当前账号。
- 多设备通过版本条件写入防止覆盖，按字段合并笔记、设置和各书位置；同一字段同时修改时，后一次成功上传的修改优先。每日记录取并集去重。
- 点击下一句计数，暂停只保存位置；北京时间当天同一条只算一次，跨天重读分别计数。旧版本未保留的历史每日数据无法补算，只迁移已有当天记录。
- 周从周一开始，周/月按天展示，年按月展示，可以翻看历史。管理员查看已上传的所有账户每日记录，支持账户及日期筛选和 CSV 文本分享导出。
- 暂未包含密码找回、修改密码、注销账号及验证码登录。正式上线需确定账号恢复与数据库运维方案。

验证：根目录 npm test；在 mobile 目录运行 npx expo export --platform web。

## 容器部署

从项目根目录运行 `docker build -f server/Dockerfile -t yijuan-accounts .`。运行时把持久化卷挂载到 /data，环境变量通过平台配置。容器仅包含 Node 后端，不包含书籍文件或开发依赖。Dockerfile 尚未在本机构建验证（需要 Docker 环境）。

费用：程序本身不要求购买数据库授权，但本版本使用持久化 SQLite 的独立服务，需要支持持久磁盘的托管平台或服务器。不能把仅提供免费临时磁盘的平台当作可靠云备份。托管数据库方案（例如 Supabase）需要另行接入对应平台，不能直接把其地址填入本版账户 API。
