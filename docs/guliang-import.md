# 《春秋榖梁传》两册导入记录

本轮按用户确认收录《榖梁传》传文，暂停《礼记》更新。客户端书名改为《春秋榖梁传》，仍使用 `chunqiu` 书籍 ID。原517条经文的正文、拼音和ID保持不变，新增747则传文，共1264条；全库5814条。

## 范围及整理

用户提供的姚政、邓启铜注释本两册 PDF 分别为271、272页。初识与复识覆盖第1册PDF第15—269页、第2册第14—269页，共511页（包括正文间的篇首插图页，插图不进入阅读正文）。两册分别覆盖隐公至文公、宣公至哀公，合计十二公、242个年份。

正文按页边方框“经”、圆框“传”分开。传文采用两轮OCR、原页裁切及通行文本候选差异核对；书中页脚现代注释、拼音、小号黑底通假提示及插图题字不作为新增正文。逐行修改与段落句读整理记录保存在 `docs/edition-review/guliang-review.json`。原PDF、逐字OCR缓存和核对图片只保存在本机忽略目录，不提交源扫描文件。

原经文继续沿用原语料及阅读分段；扫描本中的“经”用于传文定位，不能将本次理解为把经文全文替换成扫描本异文。每则传文保留册次、PDF页码和源文件SHA-256。`guliang-text.json` 保留整理后的经传块、来源行号和页码，`guliang.json` 是供客户端使用的简繁、拼音和阅读顺序数据。拼音为程序自动注音，并复用项目的古文上下文读音规则；不等同于纸书注音逐字转录，也不宣称全书逐字人工校勘。

## 阅读记录与顺序

旧书籍ID、全部原经文ID、阅读位置、收藏、笔记及已读记录仍可定位。原目录把文公十三年重复标作十二年、襄公二十七年重复标作二十六年，本次按实际年份修正标签，ID不变。

传文按全年经文字符流与旧经文单调对齐，接在对应旧经文条目之后，避免“鼓、用牲于社”等重复短句把六月传文挂到秋季。旧语料中某些条目包含一整年的多条经文，该年对应传文会跟在这个经文条目后连续展示；来源提示同时列出对应的扫描本经文以便阅读。条目在目录、阅读页和搜索结果中标明“经”或“传”。

《礼记》全部815条保持原样，已通过逐条相等测试核验；其他七部经典的版本数据也未改动。

## 维护及验证

```powershell
npm --prefix mobile run build:guliang
node mobile/scripts/build-guliang.mjs --check
npm test
```

OCR维护命令沿用 `ocr-supplied-editions.py`、`rerecognize-edition-rows.py`，随后运行 `extract-guliang-evidence.py` 生成只供核对的候选材料。该提取工具不写入客户端数据；复核后的正文由维护者进入 `guliang-text.json`。Python图像检查需要 Pillow、NumPy、OpenCV 及 pypdf，和应用依赖隔离。

本轮通过72项Node测试、20项Python测试及 `expo export --platform android`。验证包括242年结构、全部旧ID和正文保留、收藏笔记迁移、传文检索、经传对应顺序、漏行修复、字音对齐、数据重复生成和《礼记》不变。
