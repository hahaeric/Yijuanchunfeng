# Reading fonts

The app bundles these fonts so the reading styles work offline on iOS, Android, and web.

| Style | File | Source and license |
| --- | --- | --- |
| 篆书 | `ShuowenSeal.ttf` | CNS11643, Ministry of Digital Affairs, Taiwan. Downloaded from the [official CNS11643 font page](https://www.cns11643.gov.tw/downloadList.jsp?ID=2). The site publishes the Government Open Data License 1.0 and SIL Open Font License 1.1 terms at its [license page](https://www.cns11643.gov.tw/pageView.jsp?ID=59). Attribution: 数位发展部，CNS11643 中文标准交换码全字库网站。 |
| 隶书 | `AlimamaDaoLiTi.ttf` | 阿里妈妈刀隶体, Alibaba Design. See the [Alibaba Fonts portal](https://www.alibabafonts.com/) for the publisher's font terms. The original font file is bundled unchanged. |
| 楷书 | `MaShanZheng-Regular.ttf` | [Ma Shan Zheng](https://github.com/googlefonts/mashanzheng), SIL Open Font License 1.1; license text is in `MaShanZheng-OFL.txt`. |
| 行书 | `ZhiMangXing-Regular.ttf` | [Zhi Mang Xing](https://github.com/google/fonts/tree/main/ofl/zhimangxing), SIL Open Font License 1.1; license text is in `ZhiMangXing-OFL.txt`. |
| 草书 | `LiuJianMaoCao-Regular.ttf` | [Liu Jian Mao Cao](https://github.com/google/fonts/tree/main/ofl/liujianmaocao), SIL Open Font License 1.1; license text is in `LiuJianMaoCao-OFL.txt`. |

Some fonts do not include every character in all nine books. Unsupported characters fall back to the platform's regular font so the text remains readable.
